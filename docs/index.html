Features

📋

CloudWatch Logs

Search, multi-select, and tail multiple log groups simultaneously. JSON logs auto-format as tables for easy reading.

📦

S3 Browser

Browse buckets, navigate folders, download and delete files, preview text content, and copy S3 URIs to clipboard.

⌨️

Keyboard-First

Vim-style navigation with intuitive keybindings. Everything is accessible without touching your mouse.

🔧

AWS Profile Support

Works seamlessly with AWS CLI profiles and environment variables. Switch regions on the fly.

💾

Remembers Settings

Automatically saves your last used region and service. Jump right back into work.

🔌

Extensible

Built with a pluggable architecture. More AWS services coming soon.

Installation

Choose your preferred installation method

Homebrew (Recommended)

brew install sachamama/tap/sacha

Go Install

go install github.com/sachamama/sacha/cmd/sacha@latest

Download Binary

# macOS (Apple Silicon)
curl -Lo sacha.tar.gz https://github.com/Sachamama/sacha/releases/latest/download/sacha_darwin_arm64.tar.gz
tar xzf sacha.tar.gz && sudo mv sacha /usr/local/bin/

Build from Source

git clone https://github.com/Sachamama/sacha.git
cd sacha && make build
# Binary at ./bin/sacha
